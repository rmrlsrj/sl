# OBS Setlist

OBS에서 방송 중 현재 부르는 노래와 다음 곡을 표시하기 위한 간단한 세트리스트입니다.

## 특징

- OBS 브라우저 소스로 사용
- 별도의 서버 없이 브라우저에서 동작
- 입력한 곡 목록과 설정은 브라우저에 저장
- 별도의 서버로 곡 목록을 전송하지 않음
- 네이버 글꼴 사용

## 사용 방법

### 1. 제어 화면

OBS → 독 → 사용자 브라우저 독 → URL에 다음 주소를 입력합니다.

https://rmrlsrj.github.io/sl/?mode=control

### 2. 방송 화면

OBS → 소스 목록 → + → 브라우저 → 새 소스 생성 → URL에 다음 주소를 입력합니다.

https://rmrlsrj.github.io/sl/?mode=view

두 화면은 같은 브라우저 저장 데이터를 사용합니다.

## 개인정보 및 데이터

입력한 곡 목록과 설정은 사용자의 브라우저에 저장되며
별도의 서버로 전송하지 않습니다.

※ 글꼴 사용을 위해 네이버 글꼴 서버에 접속합니다.
